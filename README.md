# Ikonex Academy Student Management System

Ikonex Academy Student Management System is a full-stack web application for managing class streams, students, subjects, assessment scores, academic rankings, grade scales, and printable PDF reports. The project demonstrates frontend engineering, backend/database integration, reusable business logic, testing, and deployment readiness.

## Key Features

### Dashboard
- Overview statistics for class streams, students, subjects, and score records.
- Quick navigation cards for the main administration workflows.
- Stream shortcuts for fast access to class details.

### Class Stream Management
- Create, view, edit, and delete class streams such as `Form 1A`, `Form 1B`, and `Form 1C`.
- View a single class stream with its assigned subjects and registered students.
- Assign multiple subjects to each stream.

### Student Management
- Register students with admission number, name, gender, date of birth, and class stream.
- Search and filter students by stream.
- View individual student profiles.
- Edit student information.
- Delete students and their related score records.

### Subject Management
- Create, view, edit, and delete subjects.
- Maintain subject names, subject codes, and descriptions.
- Use subject assignments to control which assessments are entered per stream.

### Assessment & Score Entry
- Select a class stream, subject, term, and year.
- Enter continuous assessment and examination scores per student.
- Validate that CA + exam scores do not exceed 100.
- Edit existing score records and delete incorrect entries.

### Results Processing
- Automatically calculate subject totals, averages, grades, remarks, points, and positions.
- Rank students overall within a class stream.
- Rank students by subject within a class stream.
- Display report-ready class positions and subject positions.

### Grading Scale
- Configure grade bands such as A, B, C, D, and E.
- Store minimum score, maximum score, grade points, and remarks.
- Use the grading scale consistently across results and PDF reports.

### Reporting
- Generate individual PDF report cards for students.
- Generate class performance PDF reports.
- Generate subject-specific class reports.
- Include grades, averages, totals, positions, remarks, and grading keys.

## Database Design

The database is organized around the school academic workflow:

| Table | Purpose |
| --- | --- |
| `class_streams` | Stores class streams such as Form 1A or Form 2B. |
| `subjects` | Stores subject records and subject codes. |
| `stream_subjects` | Links subjects to the streams that offer them. |
| `students` | Stores learner biodata and stream assignment. |
| `scores` | Stores CA and exam scores per student, subject, term, and year. |
| `grade_scales` | Stores grade ranges, points, and remarks. |

Important database constraints include:

- Unique class stream names.
- Unique subject codes.
- Unique admission numbers.
- Unique score entry per student, subject, term, and year.
- Cascading score deletion when a student or subject is removed.
- Stream deletion unassigns students and removes stream-subject links.

## Academic Calculation Logic

The academic processing logic lives in `src/lib/grading.ts`.

It handles:

- Subject total: `CA score + exam score`
- Student total: sum of all subject totals
- Student average: total divided by number of recorded subjects
- Grade resolution from the configurable grading scale
- Subject ranking within a stream
- Overall ranking within a stream
- Report-card-ready position and class-size values

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run unit tests:



- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_SUPABASE_PROJECT_ID`
- Server-side backend secrets managed by Lovable Cloud

Do not commit private service keys or secrets into source code.

## Testing Notes

The grading tests verify the most important academic calculations:

- CA + exam total calculation
- Grade-band resolution
- Overall class ranking
- Subject-level positions
- Empty or missing score handling

The application should also be manually checked through these workflows:

1. Create a stream.
2. Create subjects.
3. Assign subjects to the stream.
4. Register students in the stream.
5. Enter scores for a term and year.
6. Review overall and subject ranking tabs.
7. Generate student and class PDF reports.
8. Edit and delete records to confirm mutations refresh the UI.
